## Hi, I'm Jeel (RJ) — Backend Engineer

I work on high-throughput backend systems: queues, workers, and the observability you need
when they start lying to you. Day job is email infrastructure at scale — warmup schedulers,
IMAP sync, bounce processing, and the ClickHouse/Grafana layer that makes it debuggable.

Most of my open-source work is the same thing in someone else's codebase: throughput bugs,
render/perf regressions, SDK edge cases, and the small correctness fixes nobody wants to chase.

**22 merged pull requests** across projects with a combined ~190k stars.
